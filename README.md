### 🔍 Project Overview
Retailers lose 15-20% revenue due to disconnected sales channels and poor inventory visibility. This project solves that by integrating sales data from multiple channels (Online, In-Store, Marketplace) into a single Power BI dashboard.

Built as part of **Data Analytics Internship @ Infotact Solutions**.

### 🎯 Business Problem
- No centralized view of sales across channels
- Stockouts & overstocking due to lack of inventory forecasting
- Unable to track customer behavior across touchpoints

### 💡 Solution Delivered
- Integrated 3 sales channels into one data model
- Designed interactive Power BI dashboard with 10+ KPIs
- Built inventory health, sales trend, and customer analytics views

### 🛠️ Tech Stack
- **Data Analysis:** Python (Pandas, NumPy), SQL, Advanced Excel
- **Visualization:** Power BI, DAX, Power Query
- **Data Cleaning:** Handling nulls, duplicates, date standardization
- **Version Control:** GitHub

### 📊 Dashboard Features
1.  **Executive Summary:** Total Sales, Profit, Orders, AOV, MoM Growth
2.  **Sales Analytics:** Channel-wise performance, Category & Region trends
3.  **Inventory Intelligence:** Stock levels, Reorder alerts, Slow-moving items
4.  **Customer Insights:** Retention, Purchase frequency, CLV

### 📈 Key Insights
- Identified top 3 high-performing categories contributing 68% revenue
- Found 22% sales drop on weekends in offline stores → staffing optimization opportunity
- Recommended inventory redistribution saving ~15% holding cost
